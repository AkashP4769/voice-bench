How this works

  1. Fetches only the selected LibriSpeech test clips and their references.
  2. Normalizes the same audio bytes before sending them to each model.
  3. Micro-averages errors across all scored reference words.
  4. Writes every run to disk, so a closed tab cannot lose the result.

New datasets can be added as benchmark providers without changing this page.
